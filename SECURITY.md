# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Code Review AI, please email security@example.com instead of using the issue tracker.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will respond to security vulnerability reports as soon as possible.

## Security Best Practices

- Keep your Node.js version up to date
- Use environment variables for sensitive data
- Review code before granting access
- Use strong authentication mechanisms

## Supported Versions

Only the latest major version receives security updates.
